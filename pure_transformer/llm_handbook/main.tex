\chapter*{Preface}
This handbook serves as a comprehensive guide for those new to Large Language Models (LLMs), specifically focusing on the decoder-only transformer architecture which powers modern systems like GPT, Llama, and Claude.

We use the \texttt{pure\_transformer} codebase as our primary reference implementation. This codebase is designed to be clean, readable, and optimized for modern hardware (A100s), utilizing state-of-the-art techniques like RoPE, SwiGLU, and Flash Attention.
